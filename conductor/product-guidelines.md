# Design Principles
*   **Warm & Cozy:** Create a welcoming digital space with soft colors, warm lighting, and an atmosphere of "coziness" that reflects the "Cozy Developer Bedroom" theme.
*   **Retro Aesthetic:** Maintain a pixel art-inspired look with high-contrast, clean lines and a playful, low-resolution charm.
*   **Interactive-First:** Prioritize smooth character navigation and responsive hitbox interactions as the primary mode of exploration.

# User Experience (UX)
*   **Minimalist & Immersive:** Keep the main screen clean, allowing the isometric artwork to shine while providing clear pathfinding for the character.
*   **Content-Clear:** Ensure all project descriptions and modals are highly readable and well-organized on both desktop and mobile devices.
*   **Playful Navigation:** Use parallax effects and smooth animations to make the room feel physically elevated and alive.

# Content & Tone
*   **Playful & Punchy:** Use short, engaging, and character-driven text for modals and tooltips to fit the "mini-game" feel.
*   **Narrative Journey:** Frame project descriptions as "discoveries" within the digital room to enhance the exploration experience.

# Interaction & Feedback
*   **Hover Glow Effects:** Implement subtle lighting or color changes when the user hovers over interactive hotspots.
*   **Retro UI Feedback:** Use pixel-inspired fonts for tooltips and typewriter effects for loading text to maintain the retro vibe.
*   **Audio Feedback (SFX):** (Optional/Future) Integrate subtle sound effects for clicks, character steps, or modal transitions to deepen immersion.
*   **Responsive Scaling:** The room and character must scale dynamically using CSS `object-fit` and JavaScript coordinate mapping to ensure a consistent experience on any screen size.
